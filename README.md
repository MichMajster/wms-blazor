# Warehouse Management System in Blazor

![Blazor](https://img.shields.io/badge/Blazor-512BD4?style=for-the-badge&logo=blazor&logoColor=white)
![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)

🇬🇧 Wms-blazor is a full-stack Warehouse Management System built with Blazor Server (.NET 8) and Clean Architecture. It provides complete data management for warehouses, locations, inventory items, contractors, and user accounts. The system features secure user authentication and role-based access control, backed by Entity Framework Core and SQL Server, with a solution structure decoupled across Domain, Application, Infrastructure, and Presentation (Blazor) layers.

🇵🇱 Wms-blazor to system zarządzania magazynem stworzony w technologii Blazor Server (.NET 8) w oparciu o zasady Clean Architecture. Pozwala zarządzać danymi magazynów, lokalizacji, przechowywanych przedmiotów, kontrahentów oraz kont użytkowników. Aplikacja została zabezpieczona poprzez uwierzytelnianie i kontrolę dostępu opartą na rolach, wykorzystując Entity Framework Core oraz SQL Server, przy zachowaniu podziału solucji na warstwy: Domain (domena), Application (aplikacja), Infrastructure (infrastruktura) oraz Presentation (prezentacja - Blazor).

* **Frontend:** Blazor WebAssembly / Blazor Server
* **Backend:** .NET / C#
* **Database:** SQL Server
